# 아카이브 원문 확보

2026-10-01 구현 범위. PDF는 기존 SHA-256 저장·백업 구조를 사용한다.

- 전체 아카이브, 선택 문헌, 분류, 미분류, 컬렉션에서 원문을 찾는다. 화면 필터와 별도로 대상 편수를 실행 전에 보여준다.
- Article_Downloader `downloader.py`의 Crossref DOI 보완, Unpaywall 후보 우선순위, 출판사 PDF 주소 규칙, PDF 링크 탐색을 Bun/TypeScript 모듈에 이식한다. CLI 호출, 임시 BibTeX, Python 설치에 의존하지 않는다.
- 기존 논문의 ID에 PDF를 연결한다. 분류·노트·읽기 상태·서지정보는 변경하지 않는다. 기존의 유효한 PDF는 건너뛰고 책·챕터는 기본 제외한다. 연도 제한은 없다.
- 네트워크·파일 크기·논문당 시도 시간을 제한하고, HTML/깨진 PDF를 첨부하지 않는다. 임시 파일 검증 후 해시 경로에 저장하고 DB를 갱신한다.
- 작업과 논문별 결과를 기존 runs 저장소에 기록한다. 취소·앱 재시작 후 성공한 첨부는 유지하고, 재개는 미처리·실패 항목만 시도한다.
- 로그인·사람 인증은 자동 우회하지 않는다. 실패 목록에서 원문 페이지를 열고 해당 논문에 PDF를 직접 연결할 수 있다. 기존 Chrome 프로필 복제·쿠키 추출·Downloads 폴더 감시는 이번 구현에 포함하지 않는다.
- 다른 프로젝트에서 공유하는 첨부, 누락 첨부 복구, 중복 해시, 삭제된 대상, 백업/복원, 서비스 종료를 검증한다.

## 구현 및 검증

- `src/service/fulltext/engine.ts`에 다운로드 엔진, `jobs.ts`에 대상 선정·체크포인트·첨부 저장을 구현했다. 기존 service 프로세스에서 실행하므로 추가 런타임 설치가 없다.
- `PDF 원문 찾기`에서 대상 편수·기존 PDF·책/챕터 제외를 확인하고 실행한다. 작업 기록에는 논문별 결과·실패 항목 재시도·원문 페이지·수동 첨부가 있다.
- 원문 확보는 새 discovery candidate를 만들지 않는다. 첨부는 기존 workId에 연결되고, 해시·최종 URL·확보 시각과 알려진 경우 원문 버전을 기록한다.
- PDF 헤더뿐 아니라 기존 PDF 작업 프로세스로 문서 파싱을 검증한다. 손상된 후보는 다음 후보를 시도한다. 알려진 DOI와 추출한 DOI/제목이 충돌하면 자동 첨부하지 않는다. 스캔 PDF처럼 메타데이터가 없는 자료의 논문 동일성까지 보장하지는 않는다.
- 사설 IP·인증정보 포함 URL 및 해당 주소로의 리디렉션을 거부한다. API 응답 2MB·PDF 150MB·개별 요청 15초·논문당 네트워크 단계 90초·최대 12개 후보로 제한한다.
- 통합 테스트 **83개 통과**. 새 원문 테스트 10개에서 HTML 오응답, 상대 PDF 링크, DOI 보완 오매칭, 손상 후보 대체, 실패 격리, 취소, 재시도, 누락 첨부 복구, 중복 해시, 분류/노트/읽기 상태, 프로젝트 공유, 병합/되돌리기·삭제, 백업/복원, 서비스 종료를 확인했다.
- `bun run typecheck`, `bun run lint`, `git diff --check` 통과.
- 최종 배포 tar를 새 디렉터리 `.qa/fulltext-release-final/ResearchBunny.app`에 풀어 제한된 PATH(`/usr/bin:/bin`)로 기존 PDF 건너뛰기·첨부·서지 내보내기·백업/복원 smoke test 통과. DMG의 앱은 압축 launcher이므로 smoke test는 압축을 푼 tar 앱에 수행한다.
- 최종 DMG의 `hdiutil verify`와 압축을 푼 앱의 `codesign --verify --deep --strict` 통과. 로컬 ad-hoc 서명이며 Developer ID 서명·공증은 하지 않았다.
- 실제 Frontiers DOI `10.3389/fpsyt.2022.867091`의 **1,264,166바이트 PDF** 확보·파싱·해시 저장·첨부 확인. 임시 라이브러리에서 검증했다.
- 별도 QA 라이브러리의 WKWebView 화면에서 전체 아카이브 실행: **새 PDF 1편, 기존 1편, 책/챕터 제외 1편, 실패 0편** 확인. 분류 편수·읽을 예정 상태·기존 노트와 PDF 첨부 표시도 확인했다. 전체 아카이브의 빈 scopeId 오류를 수정해 선택값이 없으면 전달하지 않는다.
- Bun stdin 실행 인자가 PDF worker에 상속되는 오류도 `execArgv: []`로 수정했다.
- 정상 사용자의 111편 아카이브에 일괄 다운로드하거나 설치 앱을 교체하지 않았다. 다중 출판사 확보율·기관 로그인·사람 인증은 별도 검증이 필요하다.

# 필터, 조건 반전(NOT), 컬렉션에서 빼기

필터는 문헌을 찾는 도구다. 조건에 맞는 문헌만 목록에 남고, 맞지 않는 문헌은 보이지 않는다. 컬렉션에서 일부를 빼려면 필터로 뺄 문헌을 찾아 선택한 뒤 `컬렉션에서 빼기`를 누른다. 아카이브에서 `아카이브에서 빼기`를 쓰는 것과 같다.

- 필터 조건을 하나 이상 정하면 목록 위에 한 줄이 나온다. 예: `필터 포함어 plasticity → 조건에 맞는 문헌 10편 / 30편`. 그 줄의 `조건 반전 (NOT)`이나 필터 창의 같은 체크박스를 켜면 조건 전체에 NOT이 붙는다. 그러면 목록은 조건에 맞지 않는 문헌으로 바뀐다(`NOT (포함어 plasticity) → 조건에 맞지 않는 문헌 20편 / 30편`). 필터 버튼에는 켠 조건 수가 뜨고, 반전 중에는 `NOT`이 뜬다. `조건 지우기`는 조건과 반전을 함께 끈다.
- 반전 대상은 조건(관련성, 피인용수, 출판 기간, 연도 미상, 유형, 포함어·제외어, 공통 연결, 초록·PDF·OA, 서고 보유)뿐이다. 읽기 상태 탭과 숨김 항목(저장·제외·철회 후보 숨김)은 반전해도 그대로다. 조건이 하나도 없으면 반전할 것이 없으므로 체크박스가 꺼지고, 마지막 조건을 지우면 반전도 꺼진다.
- 필터나 반전을 바꾸면 새 목록에 없는 선택은 풀린다. 보이지 않는 문헌이 선택된 채 남아 있다가 `컬렉션에서 빼기`나 휴지통에 함께 딸려 가는 일이 없다. 선택 반전은 지금 목록 안에서만 선택을 뒤집는다.
- 컬렉션은 넣어 둔 문헌을 모두 보여 준다. 일괄 편집의 `제외`는 검토 결정만 바꿀 뿐 컬렉션에서 빼지 않는다. 예전에는 기본으로 켜진 `제외 문헌 숨김`이 이런 문헌을 컬렉션에서 가렸다. 그래서 필터를 초기화해도, 앱을 다시 켜도 `필터로 제외된 문헌`과 `사용자 제외` 표시가 남았다. 이제 컬렉션 필터 창에는 이 항목이 없다. 제외로 표시한 문헌을 아카이브로 되돌리려면 컬렉션에서 골라 `저장`을 누른다.
- 0.3.27의 `제외된 문헌 보기`·`필터 결과 보기` 배너와 배너의 `컬렉션에서 빼기…` 창은 없앴다. 그때 화면별로 저장된 `filteredOut` 값은 새 필터 형식에 없으므로 읽을 때 버려지고, 그 화면은 보통 목록으로 돌아온다.

| 동작 | 빠지는 곳 | 남는 곳 |
|---|---|---|
| 컬렉션에서 빼기 | 이 컬렉션 연결만 | 아카이브, 다른 컬렉션, 서고 |
| 아카이브에서 빼기 | 아카이브 (검토 대기함으로) | 컬렉션 연결, 서고 |
| 제외 | 아카이브 (제외 문헌으로) | 컬렉션 연결, 서고 |
| 휴지통 | 이 프로젝트의 모든 목록 (복원 가능) | 서고 PDF |

## 구현

- `filterReasons`를 둘로 나눴다. `conditionReasons`는 조건에 걸린 이유를, `viewReasons`는 읽기 상태 탭과 숨김 항목에 걸린 이유를 준다. `filterConditions`는 켠 조건을 사람이 읽는 말로 돌려주며, 상태 줄과 반전 가능 여부에 쓴다.
- `Library.list`는 `viewReasons`에 걸리지 않은 문헌 수를 `scoped`로 센다. 그중 `negate`가 꺼져 있으면 조건을 모두 통과한 문헌을, 켜져 있으면 조건 하나 이상에 걸린 문헌을 목록에 담는다. 목록에 담긴 문헌의 `evidence.hidden`은 비어 있어 행에 경고 표시가 붙지 않는다. 컬렉션·휴지통·제외 문헌 화면에서는 `사용자 제외`로 숨기지 않는다. 0.3.27에서 더한 `hiddenIds`, `hiddenBy`, `filters.filteredOut`은 지웠다.
- 컬렉션에서 빼기(`Library.uncollect`)와 그 되돌리기는 0.3.27 그대로다. 선택 바의 `컬렉션에서 빼기`, Inspector의 컬렉션 칩 제거, 상단 되돌리기가 이 경로를 쓴다.

## 검증

- 타입 검사·lint 통과. 통합 테스트 316개 통과. `collections.test.ts`는 다음을 확인한다. 조건이 없으면 제외로 표시한 문헌까지 컬렉션 문헌이 모두 나오고 휴지통 문헌만 빠지는지. 조건에 맞는 문헌만 모든 페이지에 걸쳐 나오는지. NOT이 조건 하나 이상에 걸린 문헌을 경고 표시 없이 보여 주는지. 조건이 없을 때 NOT이 보통 목록과 같은지. 읽기 상태 탭은 반전하지 않는지. 컬렉션 밖에서는 제외 문헌이 계속 숨는지. NOT 결과를 컬렉션에서 빼면 조건에 맞는 문헌만 남고 아카이브는 그대로인지.
- 실제 렌더러를 임시 라이브러리(합성 문헌 30편 컬렉션, 그중 15편은 일괄 편집 `제외` 상태)에 연결해 확인했다(`.qa/uncollect/`). 이전 버전이 저장한 `filteredOut` 화면은 보통 목록으로 열렸다. `2015년부터 · 포함어 plasticity` 필터는 `6편 / 30편`을 보였고 제외 상태 문헌도 함께 셌다. NOT은 24편을 표시 없이 보였다. 24편을 선택한 채 반전을 끄자 선택이 0편이 됐다. 다시 반전하고 24편을 선택해 `컬렉션에서 빼기`를 누르자 NOT 목록이 비었고, `조건 지우기` 뒤 컬렉션에는 6편이 남았다. 되돌리기로 30편이 복원됐다. 밝은·어두운 테마를 확인했고 콘솔 오류는 없었다.

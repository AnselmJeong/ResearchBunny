# 다운로드한 PDF 폴더 연결

0.2.7에서 수동으로 확보한 PDF를 기존 아카이브 항목에 연결하고 과거 원문 확보 기록을 갱신한다.

## 사용 방법

1. 실패 목록의 DOI 페이지 또는 원문 페이지에서 PDF를 내려받는다.
2. `PDF 원문 찾기 → 다운로드한 PDF 폴더 연결`에서 PDF가 저장된 폴더를 고른다. 하위 폴더도 함께 검사한다.
3. 연결 편수와 파일별 결과를 확인한다. 모호하거나 추출할 수 없는 파일은 실패 목록의 `PDF 직접 연결`로 확인 후 첨부한다.

폴더 연결은 현재 프로젝트 아카이브의 기존 문헌만 대상으로 한다. 새 문헌·분류·컬렉션을 만들지 않으며 서지정보·노트·태그·읽기 상태를 유지한다. 유효한 첨부가 이미 있는 문헌은 건너뛴다. 연결한 파일은 원본을 유지하고 SHA-256을 검증한 복사본을 관리 저장소에 넣는다.

## 일치 판단과 결과

- 기존 자동 복구와 같은 기준을 사용한다. DOI가 일치하면 제목 유사도 0.5 이상, DOI가 검출되지 않으면 제목 유사도 0.9 이상을 요구한다. DOI가 검출되었는데 대상 문헌과 일치하지 않으면 제목만으로 자동 연결하지 않는다.
- 이미 PDF가 있는 문헌까지 포함해 후보가 하나인지 확인한다. 같은 제목의 두 문헌 중 하나에 원문이 있다는 이유로 나머지 문헌에 자동 연결하지 않는다.
- 보충자료·정오표, 불일치·모호한 후보, 추출 불가, 100MB 초과는 연결 제외 사유를 남긴다. PDF가 아닌 파일과 파일 접근·복사 오류는 실패로 기록하고 다음 파일을 진행한다.
- 같은 문헌의 동일 PDF는 중복 등록하지 않는다. 누락된 첨부 경로나 내용이 바뀐 관리 복사본은 같은 첨부 ID를 유지해 복구할 수 있다.
- 작업 취소·재개와 실패 파일 재시도를 지원한다. 다른 하위 폴더에 같은 파일명이 있어도 실패한 경로만 재시도한다. 폴더 연결 결과는 원문 확보 작업 기록과 탐색 이력에서 다시 열 수 있다.

## 과거 실패 기록

직접 첨부·폴더 연결·자동 확보 이후 등록된 PDF의 헤더와 해시를 확인한다. 첨부가 확인되면 모든 과거 원문 작업의 해당 항목을 `✓ 확보 완료`로 바꾸고 오류 코드·실패 재시도 대상에서 제거한다. UI의 최근 100개 작업 밖의 오래된 기록과 같은 문헌을 공유하는 다른 프로젝트의 기록도 갱신한다. 실행 중인 원문 작업은 외부에서 덮어쓰지 않는다.

DOI·원문 페이지를 여는 것만으로 확보 완료로 표시하지 않는다. 실제 PDF를 연결해야 완료되며, 앱을 재시작해도 완료 상태를 유지한다. 원문 대상 미리보기도 연결 직후 갱신한다.

## 검증 (2026-10-02)

- 통합 테스트 115개, 타입 검사·lint 통과. 새 테스트 6개에서 하위 폴더·중복·모호한 매칭·비아카이브·손상·누락 첨부·동명 파일 재시도·취소·재개·전체 과거 이력·프로젝트 공유·재시작과 데이터 보존을 확인했다.
- 별도 QA 라이브러리의 실제 macOS 앱에서 native 폴더 선택으로 원문 1편을 연결하고 다른 실패 항목에 PDF를 직접 연결했다. 기존 작업의 실패 2편이 0편으로 바뀌고 완료 체크가 표시됐으며 수동 다운로드·재시도 버튼이 사라졌다. 기존 PDF 미리보기 0→1→2편, 확보 시도 2→1→0편 갱신을 확인했다.
- 최종 tar의 배포 앱을 새 디렉터리에 풀어 제한된 PATH(`/usr/bin:/bin`)에서 PDF worker·폴더 연결·아카이브 보존·기존 BibTeX/PDF 폴더 내보내기·백업/복원 smoke test를 통과했다. 앱 서명 무결성과 DMG 체크섬도 확인했다. 배포 앱은 로컬 ad-hoc 서명이며 Developer ID 공증은 포함하지 않는다.
- `/Applications/ResearchBunny.app`을 0.2.7로 업데이트하고 실행을 확인했다. 교체 전 앱과 SQLite 스냅샷은 사용자 데이터 디렉터리의 `app-backups/20261002-082135-pdf-match-0.2.7`에 보관했다. 사용자 DB의 서지정보·아카이브 상태·첨부·컬렉션·소주제 테이블이 그대로이며 기존 PDF 65개의 실제 파일 해시도 등록 값과 일치함을 확인했다. 설치 앱에서 Accelerated TMS로 전환하려는 도중 사용자 조작이 감지돼 추가 화면 조작은 중단했다. 위 폴더 연결·직접 연결·미리보기·완료 표시 검증은 별도 QA 라이브러리의 실제 native UI에서 수행했다.

검증 원본과 로그는 `.qa/pdf-match-0.2.7/` 및 `.qa/pdf-match-0.2.7-*.log`에 보관한다.

# PubMed Linked Discoveries 사용

설정 → 문헌 검색에서 **PubMed Linked Discoveries 사용 (실험적)**을 켜고 **설정 저장**을 누릅니다. 기본값은 꺼짐이며 기존 사용자 설정도 그대로 유지됩니다.

PMID가 있는 논문을 선택해 **관련 논문**을 실행하면 NLM의 의미 이웃을 먼저 찾고, 이웃 PMID를 OpenAlex 문헌으로 연결합니다. 검색창에는 숫자 PMID, `pmid:38772598`, PubMed URL도 입력할 수 있습니다. 선택한 논문 상세의 **Linked Discoveries에서 보기**는 설정과 관계없이 해당 NLM 페이지를 엽니다.

- 출발 문헌 1편: 이웃 100편, 2–3편: 각 50편, 4편 이상: 각 20편을 요청합니다.
- **API 추가 조회**는 이웃 수를 20 → 50 → 100 → 200 순으로 한 단계 늘립니다. 기존 후보는 유지합니다.
- 후보의 발견 근거에 `PubMed 의미 이웃 · 유사도 0.71` 또는 여러 출발 문헌의 공통 이웃이라는 표시가 나타납니다.
- 유사도는 텍스트·주제 점수에 가산되어 순위와 관련성 필터에 반영됩니다. 초록 부족에 따른 판단 보류 표시는 유지됩니다. 유사도는 임상적 근거나 연구의 질을 평가한 점수가 아닙니다.
- 해당 출발 문헌에서 의미 이웃을 확보하면 OpenAlex `related_works`는 생략합니다. 참고문헌·후속 인용·초기 관심 검색은 계속 사용합니다.
- 빈 결과나 공급자 오류가 발생하면 OpenAlex 관련 논문으로 대체하고 완료 메시지에 미조회 출발 문헌 수를 표시합니다. 요청 한도·호출 예산 소진은 일시 중지 후 재개할 수 있습니다.

이 연동은 [NLM Linked Discoveries](https://linkeddiscoveries.ncbi.nlm.nih.gov/) 웹사이트의 비공식 엔드포인트를 사용합니다. 별도의 API 키는 필요하지 않습니다. 요청은 PC에서 직접 보내며, 앱 전체에서 직렬화하고 최소 1초 간격을 지킵니다. 식별자·유사도·개체 정보만 7일간 캐시하며 NLM 응답의 제목·초록·저자를 따로 저장하지 않습니다. 문헌 메타데이터와 초록은 기존 OpenAlex 경로를 사용합니다.

## 검증

결정적 테스트: `bun test tests/integration/linked-discoveries.test.ts --timeout 60000`

실제 엔드포인트 확인: `bun run test:live`

실시간 검사는 임시 라이브러리에서 PMID 38772598의 이웃 20편 이상과 OpenAlex 해석률 90% 이상을 확인합니다. 결과는 `artifacts/qa/live-openalex.json`에 남기며 테스트 픽스처를 덮어쓰지 않습니다. 일반 CI 테스트는 네트워크를 사용하지 않습니다.

# 서고 수신함 저장: PDF 저장소 하나로 합치기

2026-10-11 구현. 서고를 설정하면 앱이 얻는 PDF를 모두 서고 맨 위 폴더(수신함)에 저장한다. 앱 폴더(`library/attachments/`)와 서고로 나뉘어 있던 두 저장소를 하나로 합쳤다.

## 정한 사항

- **저장 위치는 서고 루트 하나다.** 별도 대기열이나 "서고로 보내기" 단계가 없다. 원문 확보(HTTP·Chrome), 다운로드 파일 복구, 폴더 연결, 직접 첨부, PDF 가져오기(`앱 관리 폴더에 복사`)가 모두 수신함에 저장한다. 서고가 없을 때만 예전처럼 앱 폴더를 쓴다.
- **앱이 서고에 하는 일은 루트에 새 파일을 추가하는 것뿐이다.** 하위 폴더로 옮기는 일은 계속 `_system/intake.py`가 한다. 앱은 파일을 옮기거나 이름을 바꾸거나 지우지 않는다. 색인은 지금처럼 읽기 전용이다.
- **Chrome 원본은 저장이 끝나면 지운다.** 검증한 사본이 서고에 들어간 뒤, Downloads의 원본이 같은 내용일 때만 지운다. 폴더 연결·직접 첨부·PDF 가져오기의 원본은 그대로 둔다.
- **서고가 오프라인이면 시작하지 않는다.** 원문 확보, 재개, PDF 가져오기, 폴더 연결은 `SHELF_OFFLINE`으로 거절한다. 작업 중에 연결이 끊기면 작업을 멈추고 해당 문헌을 `대기`로 남긴다. 앱 폴더로 우회 저장하지 않는다.

## 동작

1. 검증한 PDF를 루트에 `.researchbunny-<uuid>.part`로 복사한다. 점으로 시작하는 파일은 스캐너와 `intake.py` 모두 건너뛴다.
2. 복사본의 SHA-256을 다시 계산해 원본과 비교한 뒤 정식 이름으로 바꾼다. 같은 이름이 있으면 `intake.py`처럼 ` (2)`를 붙인다.
3. 같은 해시의 파일이 이미 서고에 있으면 복사하지 않고 그 파일에 연결한다.
4. `shelf_files`에 바로 등록한다(`stage='hashed'`, `status='ok'`, 판정 근거 `app`). 다음 스캔은 1–2쪽 추출과 임베딩만 하고 OpenAlex를 다시 부르지 않는다.
5. 첨부는 `linked` + `shelfFileId`로 저장한다. 출처 URL·확보 방식·시각은 유지한다. 파일이 하위 폴더로 옮겨지면 기존 이동 감지가 첨부 경로를 고친다.
6. 같은 바이트를 가리키던 앱 폴더 사본은 연결로 바꾸고, 더 참조되지 않으면 지운다. 지우는 대상은 `library/attachments/<hash>.pdf`뿐이다.
7. 중단된 작업이 남긴 임시 파일은 1시간이 지나면 다음 스캔이 지운다.

`설정 → 서고`에 앱 폴더에 남은 PDF 수와 `서고 수신함으로 옮기기`가 있다(`shelfAdopt`). 같은 해시가 서고에 있으면 연결하고, 서고에 같은 논문이 다른 파일로 있으면 중복을 만들지 않고 그대로 둔다.

## 파일명 규칙

`formatShelfFilename`(`src/shared/shelf.ts`)은 `parseShelfFilename`의 역함수다. 서고 파일명 8,295개에서 다수 형식을 따랐다.

| 항목 | 규칙 | 근거 |
|---|---|---|
| 형식 | `연도 - 저자 - 제목.pdf`, 연도 없음 `n.d.`, 저자 없음 `Unknown` | `intake.py`의 파일명 정규식 |
| 저자 | 1명 `Kim`, 2명 `Kim, Lee`, 3명 이상 `Kim et al.` | 2명인 논문 786편 중 632편이 `A, B` |
| 성 | 마지막 단어만, 접두어 생략(`van der Wal` → `Wal`), 대문자뿐인 성은 첫 글자만 대문자 | 접두어 있는 109편 중 86편이 생략 |
| 제목 | `:` → `; `, `? * " < > \| \ /`·제어문자·HTML 태그 제거, 끝 마침표 제거 | `;` 포함 2,641개, `:` 5개 |
| 길이 | 240바이트(UTF-8)를 넘으면 단어 경계에서 자르고 ` ...` | 잘린 이름 19개 모두 240–248바이트 |

DOI·제목으로 서지를 확인한 서고 파일 7,020개에 적용하면 80%(5,645개)는 이름이 글자 하나까지 같고, 저자 부분은 93%가 같다. 나머지는 대부분 원래 이름을 만든 서지가 OpenAlex와 다른 경우다(악센트 제거, 저자 목록·대소문자 차이).

## 실제 라이브러리 이전 (2026-10-11)

설치 앱(0.3.0)을 종료한 뒤 이 코드의 `Shelf.adoptManaged`로 앱 폴더 PDF 104개를 옮겼다. 이전 전 DB 스냅샷(`VACUUM INTO`, 무결성 검사 ok), 첨부 폴더 전체, 수신함 목록을 `~/Library/Application Support/ResearchBunny/app-backups/20261011-185455-shelf-inbox/`에 보관했다.

| 결과 | 개수 |
|---|---|
| 수신함으로 옮김 | 53 |
| 서고의 같은 파일(같은 해시)에 연결 | 5 |
| 서고에 같은 논문이 다른 파일로 있어 앱 사본을 백업으로 옮김 | 46 |

- 수신함 PDF 99 → 152개. 기존 파일은 그대로다. 남은 임시 파일은 없다.
- 104편 모두 검증되는 PDF에 연결돼 있다. 앱 폴더의 PDF는 0개다. SQLite 무결성 검사·외래 키 검사 통과.
- 46개 앱 사본은 사용자의 결정에 따라 서고 파일만 남겼다. 사본은 백업의 `replaced-by-shelf/`에, 논문·서고 파일 대응은 `replaced-by-shelf.tsv`에 있다.
- 새로 등록한 53개는 판정 근거를 `hash`로 기록했다. 설치된 0.3.0도 이 값을 알아서 다음 스캔에서 OpenAlex 없이 추출만 한다.

# 소주제별 PDF 폴더 내보내기

0.2.6 구현 범위. 기존 BibTeX 내보내기에 PDF 폴더 형식을 추가한다.

- `내보내기 → 형식 → PDF 폴더 · 소주제별 분류 유지`에서 실행한다. PDF 형식을 고르면 기본 범위는 현재 프로젝트 아카이브다. 선택한 문헌, 현재 조회 결과, 컬렉션, 모든 프로젝트도 선택할 수 있다. PDF 형식은 아카이브에 저장된 문헌만 포함한다.
- 문헌 수, 읽을 수 있는 PDF 수, PDF 없는 문헌 수와 소주제별 폴더 구조를 미리 보여준다. 실행 대상의 프로젝트와 문헌 ID는 미리보기에서 고정하며, 그 사이 아카이브에서 제거된 대상은 다시 확인하도록 안내한다.
- 선택한 저장 위치에 `<프로젝트 이름> PDFs` 폴더를 만들고 현재 소주제 이름을 하위 폴더로 유지한다. 미분류 문헌은 `미분류`에 넣는다. 여러 프로젝트를 함께 내보내면 `ResearchBunny PDFs/<프로젝트>/<소주제>` 구조를 사용한다. 여러 프로젝트가 공유하는 문헌도 각각의 분류에 복사한다.
- 관리 첨부와 외부 연결 첨부 모두 복사한다. 한 문헌의 여러 PDF는 모두 내보내되 같은 문헌의 동일 해시는 한 번만 복사한다. PDF 이름은 연도와 첨부 이름을 사용한다. 사용할 수 없는 경로 문자는 정리하고 긴 이름을 제한한다. 이름이 충돌하면 번호를 붙여 구분한다.
- 원본 PDF·서지정보·분류·노트·읽기 상태를 변경하지 않는다. 기존 출력 폴더와 파일도 덮어쓰지 않는다. 선택한 볼륨의 임시 폴더에 복사하고 각 복사본의 SHA-256을 등록된 첨부 해시와 확인한 뒤 새 폴더로 확정한다.
- 첨부 없음, 원본 접근 불가, 해시 불일치는 `내보내기 결과.csv`에 문헌별로 기록한다. 읽을 수 없는 첨부가 있어도 다른 문헌은 진행한다. 저장 위치의 쓰기 실패는 전체 출력을 중단하고 임시 파일을 정리한다. 결과 CSV는 노트·태그·로컬 원본 절대 경로를 포함하지 않는다.
- 기존 BibTeX 옵션·선택 범위·파일 저장 동작은 유지한다. 성공한 PDF 폴더 내보내기도 기존 `export_records`에 기록한다.

## 검증 기록 (2026-10-02)

- 타입 검사·lint·통합 테스트 **109개 통과**. 새 통합 테스트 5개에서 분류 폴더·미분류·빈 범주, 외부 연결 첨부와 다중 PDF, 누락·내용 변경, 이름 충돌·경로 정리, 기존 출력 보존, 다중 프로젝트의 공유 문헌, 미리보기 대상 고정, 아카이브 제거, 내보내기 이력과 BibTeX 호환을 확인했다.
- 기존 Chrome 테스트가 개발 Mac의 다운로드 설정에 의존하지 않도록 각 테스트의 임시 폴더를 지정했다. 비동기 PDF worker의 완료를 충분히 기다리고 실패 정리 때 작업을 중단·대기한 뒤 DB를 닫아 후속 테스트에 오류를 전파하지 않게 했다.
- 최종 tar의 앱에서 제한된 PATH(`/usr/bin:/bin`)로 PDF 추출·아카이브·BibTeX와 PDF 폴더 내보내기·백업·복원 smoke test를 통과했다. 테스트 harness의 서비스 fork에는 `execArgv: []`를 지정해 부모의 `bun -e` 실행 인자가 상속되지 않게 했다. 앱 서명 무결성과 DMG 체크섬도 검증했다.
- 사용자 DB의 읽기 전용 스냅샷에서 Accelerated TMS **111편·65개 PDF·10개 소주제 폴더**를 내보냈다. PDF 없는 46편은 결과 CSV에 기록됐다. 각 출력 파일의 해시가 해당 문헌의 첨부와 같고 원본·아카이브 상태가 그대로임을 확인했다.
- `/Applications/ResearchBunny.app`을 **0.2.6**으로 교체한 뒤 실제 UI에서 PDF 형식, 현재 아카이브 범위, 111편·65개 PDF·46편 미첨부, 10개 폴더 미리보기와 native 저장 위치 선택을 확인했다. 설치 앱의 UI로 65개 PDF를 내보내고 복사본·원본 해시, 정확한 분류 폴더, 결과 CSV 111행과 내보내기 이력 등록을 확인했다. 기존 서지정보·분류·노트·읽기 상태·첨부 DB 행은 바뀌지 않았다.
- 실제 UI 출력: `.qa/pdf-export-0.2.6/ui-export-parent/Accelerated TMS PDFs`. QA 원본과 설치 검증 결과는 `.qa/pdf-export-0.2.6/`에 보관한다. 교체 전 0.2.5 앱과 DB는 사용자 데이터 디렉터리의 `app-backups/20261002-075353-pdf-export-0.2.6`에 보관했다.

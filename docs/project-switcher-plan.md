# 프로젝트 전환과 생성

- 앞글자 배지와 별도 `+` 버튼을 없애고, 프로젝트명과 펼침 표시가 있는 하나의 버튼으로 전환한다.
- 목록은 앱의 테마를 따르며 현재 프로젝트에 체크를 표시한다. 긴 이름은 목록에서 줄바꿈한다.
- 목록 아래 `새 프로젝트 만들기`를 배치한다. 같은 팝오버에서 이름을 입력하고 만들며 연구 질문은 선택 사항으로 접는다.
- 생성 중 중복 제출을 막고 오류는 입력 내용과 함께 유지한다. 바깥 클릭이나 Escape로 닫은 초안은 다시 열 수 있다.
- 방향키·Home·End로 목록을 이동하고 Enter로 선택한다. Escape, 바깥 클릭, 초점 복귀를 확인한다.
- 기존 탐색 상태 저장과 서비스 API를 유지한다. 별도의 QA 라이브러리로 전환·생성·재시작 후 지속성을 확인하고 타입·린트·렌더러 빌드를 검증한다.

## 검증

- 타입 검사와 전체 린트 통과, Safari 17 대상 렌더러 빌드 성공.
- 독립 SQLite 라이브러리를 연결한 Chromium UI 검사: 프로젝트 전환 시 선택 문헌·정렬 복원, 현재 프로젝트 체크, 방향키·Home·End·Enter·Escape·Tab, 초점 복귀 확인.
- 이름만으로 생성 및 선택적 연구 질문 저장, 공백 이름 차단, 빠른 중복 제출 차단, 오류 후 재시도, 닫았다 다시 연 초안 복원, 새로고침 후 프로젝트 지속성 확인.
- 긴 이름의 목록 줄바꿈·사이드바 및 상단 경로 말줄임, 작은 창에서 팝오버 경계, 밝은/어두운 테마 확인. 렌더러 오류 없음.
- QA 서버·검증 스크립트·스크린샷은 `.qa/project-switcher/`에 보관한다.
- 후속 배포 요청으로 0.2.10 설치본을 교체하고 macOS 기본 WebKit에서 목록 열기, 생성 폼, 이름 입력, 선택적 연구 질문 펼치기, 취소 및 Escape 초점 복귀를 확인했다. 배포 기록은 [0.2.10](release-0.2.10.md)을 참고한다.

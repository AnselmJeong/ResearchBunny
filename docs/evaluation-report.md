# 추천 평가 상태 · 0.1.0

2026-09-26 기준, **GPT 추천 품질 통과를 주장하지 않는다.** 선택 기능을 구현하고 실험 표시·기본 비활성 상태로 배포한다. 실제 OpenAI API 호출에는 사용자가 설정한 키가 필요하다.

## 구현하고 검증한 경계

- 연구 질문 → 최대 8개 구조화 검색식 → OpenAlex 검색·대표 후보의 제한된 인용 이웃 → 실제 ID 중복 제거 → 최대 60편 평가 → ID/근거 allowlist 검증.
- Structured Outputs와 별도로 후보 ID, 중복 ID, 근거 ID, 제공 원문의 정확한 인용문, 제공되지 않은 숫자를 검사한다.
- 테스트에서 가짜 ID·없는 인용문·추가 수치·가짜 근거·중복 추천을 거부했다. 일반 필터가 최신 저인용 문헌을 인용수만으로 제거하지 않고, 무관한 고인용 문헌이 엄격 관련성 조건을 우회하지 않음을 확인했다.
- 모델·프롬프트 버전·입력·후보·사용량·예산·결과를 실행 기록에 남긴다. 호출·출력 토큰·예상 금액을 제한하고 공급자 오류 시 검증된 검색 후보를 유지한다.
- 근거 ID와 인용문이 존재해도 해석 전체가 지지되는지는 자동 검증하지 못한다.

## 미측정 항목

PRD 9.3이 요구한 5개 질문 × 질문당 사람이 검토한 50편 이상의 평가 세트가 아직 없다. 실제 GPT 응답, 유료 호출 지연·비용, 인간 판단에 대한 Precision@10·nDCG@10, 알려진 핵심 문헌 회수율은 **미측정**이다. 합성 fixture를 사람 평가로 대체하거나 임의 점수를 보고하지 않았다.

일반 검색·피인용순·내용+관계·GPT 추가의 동일 예산 비교와 오류 분석이 끝나기 전까지 AI를 기본 진입점으로 승격하지 않는다. 평가 질문 4/5 이상에서 상위 10편 중 적합한 문헌 7편 이상, 기준선 대비 평균 개선, 치명적 근거 오류 0건이라는 PRD의 잠정 기준을 유지한다.

# 현재 미연결 원문 목록 · 0.2.8

2026-10-02. `PDF 원문 찾기`를 원문이 없는 문헌을 하나씩 해결하는 화면으로 변경했다.

- 날짜별 기록 선택을 없애고 실제 PDF 파일·해시에서 현재 연결 수와 남은 목록을 계산한다. 과거 기록이 없는 문헌도 표시하며 과거 성공 PDF가 없거나 손상되면 재연결 대상으로 표시한다.
- 남은 문헌마다 원문 페이지·DOI 페이지·PDF 직접 연결을 제공한다. 페이지 열기만으로는 목록에서 제거하지 않는다. 자동 확보·폴더 연결·직접 첨부 후 검증한 PDF가 있으면 제거한다.
- 자동 재시도는 현재 남은 문헌을 대상으로 한다. 실행 중 진행·취소·건너뛰기를 제공하고 취소·중단 후에도 남은 목록에서 다시 시작한다.
- 폴더 연결 결과는 요약하고 파일별 결과는 기본으로 접어 둔다. 원문 확보·폴더 연결은 탐색 이력과 최근 탐색에 표시하지 않는다. 내부 실행 데이터는 복구·오류 안내에 사용하며 기존 기록을 삭제하지 않는다.
- 범위 변경과 작업 변경에 맞춰 갱신하며 화면이 열린 동안 3초마다 확인한다. 모든 남은 문헌을 50편씩 더 볼 수 있고 자동 확보는 한 번에 최대 1,000편을 처리한다. 책·챕터는 기본 제외하며 설정에서 포함할 수 있다.

## 검증

- 통합 테스트 121개 통과. 새 문헌, 책 제외, 프로젝트·선택·분류·컬렉션 범위, 100개 이전 실행의 오류, 진행 중 재시도, 파일 손실·변조, 1,001편 아카이브, 폴더·직접·자동 첨부 후 목록 축소를 검증했다.
- 타입 검사·lint·`git diff --check` 통과.
- 별도 QA 라이브러리의 실제 앱 화면에서 `2편 → 폴더 연결 후 1편 → PDF 직접 연결 후 0편`을 확인했다. 화면을 닫거나 과거 기록을 선택하지 않았다. 해결된 논문과 세 수동 버튼이 사라지고 폴더 상세는 접힌 상태로 유지됐다.
- 최종 패키지의 제한된 PATH 런타임 검사 통과. PDF 추출·현재 남은 목록 조회·폴더 연결·아카이브·BibTeX/PDF 내보내기·백업·복원을 검증했다. 앱 서명 무결성과 DMG 체크섬을 확인했다. 로컬 ad-hoc 서명이며 공증된 배포를 의미하지 않는다.
- `/Applications/ResearchBunny.app`를 0.2.8로 갱신하고 실제 Accelerated TMS 프로젝트에서 `대상 111편 · PDF 연결 69편 · 남은 문헌 41편 · 책·챕터 제외 1편`과 수동 버튼을 확인했다. 기존 4편 연결 결과는 요약으로, 남은 41편은 바로 아래 목록으로 표시됐다. 실제 추가 다운로드는 실행하지 않았다.
- 갱신 전후 문헌·프로젝트별 상태·첨부·컬렉션·분류 테이블의 해시가 동일하고 69개 기존 PDF 해시가 모두 일치했다. SQLite 무결성 검사도 통과했다. 이전 앱과 DB 백업은 `~/Library/Application Support/ResearchBunny/app-backups/20261002-095435-current-fulltext-0.2.8`에 보관했다.

검증 로그·QA 데이터는 `.qa/current-fulltext-0.2.8*`에 있으며 설치 파일은 `out/electrobun/stable-macos-arm64-ResearchBunny.dmg`이다.
